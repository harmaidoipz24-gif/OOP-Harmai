Лабораторна робота №2 присвячена дослідженню життєвого циклу об’єктів та реалізації перевантажених конструкторів у C# на прикладі класу BankAccount. У межах проєкту реалізовано інкапсуляцію даних за допомогою приватних полів і публічних властивостей із валідацією, бізнес-методи Deposit та Withdraw для управління балансом, а також ланцюговий виклик конструкторів через ключове слово : this(), що усунуло дублювання коду ініціалізації. Демонстрація роботи програми охоплює створення об'єктів із різними наборами параметрів, перевірку коректності вхідних даних та підтвердження очищення пам'яті збирачем сміття (Garbage Collector) через спрацювання деструктора ~BankAccount().
