# Звіт з лабораторної роботи №1
**Тема:** Об'єктно-орієнтоване програмування в C# та контроль версій Git  
**Варіант №6:** Клас `BankAccount`

В ході виконання лабораторної роботи №1 з дисципліни «Об’єктно-орієнтоване програмування» було розроблено консольний застосунок на платформі .NET (C#) для варіанта №6, у межах якого реалізовано клас `BankAccount` з приватними полями (`owner`, `accountNumber`, `balance`), публічною властивістю `Balance` для безпечного доступу до даних та методами `Deposit()` і `Withdraw()` для поповнення та зняття коштів з перевіркою коректності суми й балансу. У файлі `Program.cs` створено 3 об'єкти даного класу, продемонстровано їхню взаємодію з методами та виведено результати операцій у консоль, а також налаштовано контроль версій Git із відповідним файлом `.gitignore` та успішно завантажено проєкт до віддаленого репозиторію на GitHub.
